Настройка инфраструктуры: Windows Server 2022 + Active Directory
Цель:
Развернуть контроллер домена Windows Server 2022 в виртуальной среде VirtualBox
Параметры виртуальной машины
- ОС: Windows Server 2022 Standard (Desktop Experience)
- RAM: 4096 МБ
- CPU: 2 ядра
- Диск: 40 ГБ
- Имя хоста DC01
- Домен: dinar.local
- IP-адрес: 192.168.56.10

Установка Windows Server 2022
1. Создал виртуальную машину в Oracle VirtualBox 
2. Подключил ISO-образ Windows Server 2022
3. Выбрал установку с графическим интерфейсом (Desktop Experience)
4. Задал пароль администратора
5. Установил Guest Additions для удобства работы

Установка роли Active Directory Domain Services
Открыл Диспетчер серверов → Добавить роли и компоненты
Выбрал роль "Доменные службы Active Directory"
Добавил средства управления
После установки нажал "Повысить этот сервер до контроллера домена"
Выбрал "Добавить новый лес"
Указал имя домена: dinar.local
Задал пароль DSRM

Проверил установку командой dcdiag /test:dns /v , все тесты DNS прошли успешно
